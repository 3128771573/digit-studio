# 第 1 章 写下一个 3，电脑看到了什么

## 一笔和一个标签，是两种东西
在纸上写一个 3。人看到的是字符，图像文件记录的是不同位置的亮度。模型接收亮度数组，输出十个数；把最大数对应的索引叫作预测类别。这一过程没有自动获得“第三个自然数”的含义。训练标签建立了图像与符号 3 的统计联系。

想象把纸盖上一张细方格网，每格只记录一个亮度。一格就是一个像素。灰度图像通常以 0 表示黑，255 表示白。MNIST 数据恰好采用黑底亮字，因此笔画位置较亮。网页画布是白底深色笔迹，必须在输入模型前转换。这个方向差异会贯穿全书：显示给人的图片，未必就是网络直接收到的数组。

像素没有厘米单位，它是编码后的亮度值。8 位整数只能容纳 0 到 255；浮点数可以表示小数。把整数除以 255，是换一种数值尺度，不是增加照片细节。放大一张 28×28 图片也不会凭空得到真实笔画。

## A：先读懂一张小图片
我们先用 3×3 的示意图，而不是全部 784 个像素。下面的数值以黑底亮字为约定，范围 0 到 1。

```text

0.0  0.5  1.0
0.0  1.0  0.0
```

第一行第二列是 1.0，表示很亮；中间是 0.5，表示中等亮度。这不是一个真实 MNIST 样本，只是用来读坐标的示意。图 1 把数组位置和图像方格连接起来。不要认为每个像素只有“有笔画”和“没笔画”两种状态：抗锯齿、扫描和缩放都会产生灰色边缘。

@figure pixels | 图 1　位置决定意义：同样九个数，改变排列就会改变图像。示意数据，非实验结果。

一个数叫标量；按顺序排列的一串数叫向量；有行和列的二维数组叫矩阵；推广到更多维叫张量。“张量”在本书首先表示一个带形状的数值数组，不需要先理解更抽象的几何定义。

# 第 2 章 不用神经网络，能认出来吗

## 如果用“最像谁”来判断
如果某幅图像和已知的 3 很接近，也许它也是 3。于是可以储存十幅参考图，把新图片与每幅参考图逐像素比较。最简单的方法是平方距离：每个位置的差平方后相加。这样差的正负不会互相抵消。

@math d(x,t)^2=\sum_{i=0}^{783}(x_i-t_i)^2

这里 x 和 t 是 784 维向量，i 是位置索引，d² 是平方距离。距离越小，逐位置亮度越相似。对 x=[0,1]、t=[1,1]，平方距离是 (0−1)²+(1−1)²=1。对 u=[0,0]，距离也等于 1。这说明距离相同可能需要明确并列规则，代码 argmax/argmin 默认选择先出现的索引，不能把并列解释为确定证据。

只选一位同学的字体太偏。我们可以把训练集中同类的图像求平均，得到十个类别平均图。第 c 类第 i 个位置的模板是该类所有样本在 i 位置的平均亮度。

@math t_{c,i}=\frac{1}{n_c}\sum_{k:y_k=c}x_{k,i}

n_c 表示该类训练样本数。若该类一个样本也没有，这个式子没有定义，实验代码会报错，而不是默默给零模板。平均图会比较模糊：它汇总了各种字体和位置，不是某个真实人的笔迹。

## 一个成功也不能掩盖的弱点
假如把同一个 3 向右移动两格，语义标签没有改变，但对应像素发生了许多变化。平方距离看到的仍是位置差异，不知道“这是同一幅图移了一点”。先预测这个变化会怎样影响模板排序，再去实验。模板法的不足来自所选距离与表示，不是因为电脑“没有理解能力”的一句泛泛描述。

同一标签可能有多种字形；不同标签可能共享笔画。平均图把各种写法融合，可能离任何一张实际图片都不够近。规则识别也类似：人为设置“上下两个弧线”规则后，还要解决倾斜、断笔、粗细和噪声。如果规则能覆盖你的输入分布，它可以有用；并非所有任务都必须神经网络。

## 实验 2：建立有记录的基线
完整文件是 textbook/labs/template.py。主角是 sums，形状 (10,784)，储存各类像素总和；counts 是 (10,)，储存各类样本数；means=sums/counts[:,None]，通过增加一个维度使每类数量作用于该类所有像素。

```python
means = sums / counts[:, None]
scores = -(x.flatten(1)[:, None] - means[None]).square().sum(2)
prediction = scores.argmax(1)
```

输入 x 是 (N,1,28,28)，展平后 (N,784)。差值是 (N,10,784)，最后沿像素维求和，得到 (N,10)。负距离使“更大分数”对应“更近”。这些分数不是天然校准的概率；对它们强行 Softmax 可以得到和为 1 的数，却不自动给距离一个合理温度。因此配套模板结果不拿交叉熵与神经网络作公平比较。

# 第 3 章 给数值一个合适的位置

## 展平不会删除数值，但会改变我们如何使用位置
把 28×28 展成 784 维，像把一张棋盘按行读成一串棋格。只要记住顺序和原形状，可以 reshape 回去。展平本身不会损失像素；问题在于后续模型是否利用二维邻接关系。

```python
flat = images.flatten(1)       # (N, 784), preserve N
restored = flat.reshape(-1, 1, 28, 28)
```

−1 表示让程序根据元素总数推算那一维。它不是任意值：不能把 784 个数 reshape 成 (30,30)。flatten(0) 会把批次也混进去，破坏“一行一个样本”的约定，是常见错误。transpose 调换维度顺序；reshape 重解释元素布局，两者用途不同。

## A：点积是“同位置相乘，再相加”
向量 x=[1,2,3] 与 w=[2,0,−1] 的点积是 2+0−3=−1。元素乘法结果是 [2,0,−3]，仍然是向量。Python/NumPy/PyTorch 中 * 通常表示元素乘法，@ 表示矩阵乘法。两者不能互换。

@math w^T x=\sum_{i=0}^{d-1}w_i x_i

T 表示转置，不是平方。w 与 x 是 d×1 列向量；wᵀ 是 1×d，乘 x 得 1×1 标量。矩阵乘法 (a,b)@(b,c) 得 (a,c)，中间维度必须一致。这种形状检查是低成本的排错工具。

图 3 给出代码常用的批量布局：X 是 (N,d)，W 是 (K,d)，所以 Z=XWᵀ+b 是 (N,K)。b 是 (K,)，广播到 N 行。若误写 X@W，往往维度错误；某些方阵下却能运行，计算仍然错，因此“能跑”不等于“含义对”。

@figure shapes | 图 3　矩阵乘法检查。每个输出分数，来自一行样本与一行类别权重的点积。

## A：均值、方差与标准差
均值把一组数的总和除以数量。方差衡量偏离均值的平方距离平均；标准差是方差的平方根，因此回到原数值尺度。对 [0,1,2]，均值 1，总体方差 2/3，标准差约 0.816497。若估计总体方差时使用无偏样本估计，分母是 n−1，本例得到 1。必须说明自己采用哪个定义。

@math \mu=\frac{1}{n}\sum_i a_i,\quad \sigma^2=\frac{1}{n}\sum_i(a_i-\mu)^2

本书普通标准化写成 (a−μ)/σ。项目使用固定 μ=0.1307、σ=0.3081，先把像素除以 255，再标准化。于是黑底 0 变成约 −0.424213，亮笔画 1 变成约 2.821904。这不是每幅图各自重新计算均值和方差，也不保证每张图片恰好均值 0、方差 1。

“归一化”是宽泛术语，常指把值缩放到某个范围；“标准化”在这里特指减均值、除标准差。预处理必须和训练约定匹配。如果训练看标准化数值，预测却只做 /255，网络会看到不同分布。

## 为什么最后一个小批次不能和大批次等权
一个批次 64 个样本平均损失 1，最后一个批次只有 6 个样本平均损失 3。总平均应为 (64×1+6×3)/70=1.171429，而不是 (1+3)/2=2。每个样本等权，才能与逐样本求和一致。

@math \bar L=\frac{\sum_b n_b\bar L_b}{\sum_b n_b}

这里 b 是批次索引，不是神经元偏置；上下文会区别。训练代码累加 loss.item()*len(y)，再除以 total。Accuracy 也应累加正确数量再除样本数，而不是简单平均批次百分数。

# 第 4 章 第一个会学习的分类器

## 权重不再由我们手写
一个神经元先计算 z=wᵀx+b。权重 w 决定各输入如何影响分数，偏置 b 决定所有输入为零时的起点。对 x=[2,1]、w=[0.5,−1]、b=0.2，z=1−1+0.2=0.2。权重为负不是“坏参数”，只是该特征增加时分数会减少。

@math z=w^T x+b

识别十类需要十个分数。将十组权重放成矩阵 W∈R^(10×784)，b∈R^10；单样本列向量 x∈R^784，z=Wx+b∈R^10。批次按行储存时，换成 Z=XWᵀ+b。PyTorch Linear(784,10) 的 weight 形状就是 (10,784)。

相邻两类 a、c 的分界满足 z_a=z_c，也就是 (w_a−w_c)ᵀx+(b_a−b_c)=0。这是一个仿射超平面。三维以上无法直接画出来，但含义仍然是输入空间被线性分数比较分割。这里“线性分类器”沿用常见叫法，严格说含偏置的计算是仿射变换。

## 第一份模型只要两层容器
文件 textbook/labs/models.py 的 linear 分支是完整定义；Flatten 没有可训练参数，Linear 有 784×10 个权重和 10 个偏置，总共 7,850 个参数。

```python
from torch import nn

model = nn.Sequential(
    nn.Flatten(1),
    nn.Linear(784, 10),
)
logits = model(images)    # (N, 10)
```

nn.Module 是可组合的网络组件；Sequential 按写出的顺序运行。model(images) 调用前向计算。初始权重是随机初始化的，并非模板平均图。参数与超参数不同：权重和偏置由训练更新，学习率、层宽和 batch size 则是你先选的设置。

这里 images 指从 DataLoader 得到的批次，不是 PIL 图片；Linear 的两个位置参数是输入长度、输出长度。后面 padding=1、lr=0.001 这种写法是关键字参数，用名字说明设置。完整脚本的 def make_model(name) 把模型构造放进可重复调用的函数；return 返回构造出的模型。你暂时不必自己写 nn.Module 子类，Sequential 已能完成前三种基础结构。

## 为什么最大分数还不够训练
argmax 能告诉我们哪一类排第一，却不能平滑描述“离正确答案近了多少”。目标类从第二名变成只差一点的第二名时，预测标签不变；训练仍应知道取得了进展。我们需要把分数转换为一组可比较数值，再用一个连续损失评估错误。下一章正是解决这个问题。

# 第 5 章 从十个分数到可训练的错误

## A：为什么用指数与归一化
logits 可以是负数，也不需要和为 1。Softmax 将它们转换成正数，再除以总和。指数函数 exp(z) 始终为正且严格递增；因此分数大小顺序被保留，并放大分数差异对应的比值。

@math p_j=\frac{e^{z_j}}{\sum_{k=0}^{K-1}e^{z_k}}

K 是类别数，p_j 是模型分配给第 j 类的数值。对于 [2,1,0]，指数约 [7.389056,2.718282,1]，概率约 [0.665241,0.244728,0.090031]，和为 1。若把一个 logit 增加 1，它相对另一个类的概率比会乘以 e；不是概率本身简单加 1。

大数指数容易溢出。令 m=max(z)，先减去 m。每个指数都乘了 e^(−m)，分子分母共同因子抵消，所以结果不变：

@math \frac{e^{z_j-m}}{\sum_k e^{z_k-m}}=\frac{e^{-m}e^{z_j}}{e^{-m}\sum_k e^{z_k}}=p_j

这时最大指数是 1，数值更稳。Softmax 的 argmax 与 logits 相同，有限输入下概率排序也相同；浮点舍入和并列仍要按实现解释。

## 十个类里必须分完，不代表知道世界上只有十个类
给模型一张猫、一封信或者两个数字，Softmax 仍把总量分给 0–9。高概率可能只是某类比另外九类分数高很多。它没有自动新增“未知”类别。空白检测是输入规则，不是通用未知检测；完整未知拒识需要额外数据、评价方法与设计。

比例是两个数量的比；百分数只是比例乘 100 后的表达。经验频率来自实际计数；模型概率来自当前参数下的输出。后者是否接近同类预测的真实正确频率，需要校准评估，不能因总和为 1 就宣布可信。

## A：交叉熵为什么惩罚自信的错误
若真实类别是 y，希望 p_y 大。取负对数得到 L=−ln(p_y)。p_y 趋近 1 时损失趋近 0；p_y 很小时损失很大。对数把概率乘积变成和，这是从独立样本似然到训练总损失的桥梁。独立建模是一个建模假设，不是所有现实数据天然独立。

@math L=-\ln p_y=-z_y+\ln\left(\sum_k e^{z_k}\right)

p_y=0.9 时 L≈0.105361；0.5 时≈0.693147；0.1 时≈2.302585。每个值都必须用自然对数。如果把 ln 换成 log10，损失和梯度尺度会改变。损失不是错误百分比，不能把 0.2 loss 说成 20% 错误。

对于 N 个样本，无类别权重、无忽略标签的普通平均交叉熵为 L_batch=(1/N)∑L_n。PyTorch CrossEntropyLoss 接收原始 logits 与 int64 类别索引，内部稳定计算 LogSoftmax 和目标类别负对数。先 Softmax 再把概率交给它，会把概率当作新 logits，改变目标。

```python
logits = model(x)
loss = torch.nn.functional.cross_entropy(logits, y)
probabilities = logits.softmax(dim=1)  # for inspection, not CE input
```

参考 [R1]：PyTorch 2.14 CrossEntropyLoss。带 class weight、ignore_index、软标签时平均规则不能机械套用 N；本书基础实验没有这些选项。

## B：完整推导输出梯度
用上面 L=−z_y+ln S，S=∑exp(z_k)。第一项对 z_j 的导数：j=y 时 −1，其他时候 0，写成 −1[j=y]。第二项按链式法则：ln S 对 S 的导数 1/S，S 对 z_j 的导数 exp(z_j)，乘积就是 p_j。因此：

@math \frac{\partial L}{\partial z_j}=p_j-\mathbf{1}[j=y]

真实类的梯度通常为负：梯度下降会增大其 logit；其他类为正：下降会减小其 logit。但这些 logits 同时依赖许多共享参数，实际更新对不同样本可能产生竞争，不应把这一局部结论说成每一步所有样本都改善。

另一种检查从 Softmax 导数开始：∂p_i/∂z_j=p_i(1[i=j]−p_j)，再乘 ∂L/∂p_y=−1/p_y，得到同样结果。第一种推导更短，也解释为什么稳定实现合并运算。

批次平均的 G_nj=(p_nj−1[j=y_n])/N。除 N 必须明确；如果采用求和损失，则没有这个因子。教材 checks 的 float64 自动求导与有限差分核对这个式子。

## 实验 5：标签没变，损失也可能变
固定真实标签为 0，分别比较 logits=[2,1,0] 与 [3,1,0] 的损失。预测都为 0，第二组目标概率更大，损失更小。再构造多数样本刚跨过分界、一个错误变得极其自信的例子：Accuracy 可能升高而平均 Loss 升高。记录逐样本损失，才知道原因。

# 第 6 章 一个参数怎样挪一步

## A：导数是一把局部尺子
把参数 w 稍微改动 ε，观察损失变化。差商 [L(w+ε)−L(w)]/ε 是局部变化率的近似；导数是 ε 趋近 0 时的极限。这里不需要先做长篇极限证明，要先理解它回答的问题：当前位置向哪边小步移动，损失更可能下降？

对 L(w)=(2w−3)²/2，w=0.5 时预测 1，损失 2；导数 L′(w)=2(2w−3)=−4。η=0.1 时 w_new=w−ηL′=0.9，新预测 1.8，损失 0.72。注意这次只更新 w；若同时更新偏置，结果不同，下一节会明确。

@math \theta_{new}=\theta-\eta\nabla_\theta L

θ 是所有参数构成的向量，η 是学习率，梯度每个分量是损失对那个参数的偏导。梯度指向局部最陡上升方向，负梯度指向下降方向；这是在通常欧氏距离度量下的描述。一步太大可能越过低谷，不能把“方向对”说成“任意步长都对”。

@figure update | 图 4　局部斜率与更新。曲线为 L(w)=(2w−3)²/2 的解析示意，箭头表示一次小步更新。

## B：链式法则把分数和参数连起来
设 z=wx+b，L=(z−y)²/2。先求 ∂L/∂z=z−y，再求 ∂z/∂w=x，相乘得到 ∂L/∂w=(z−y)x；∂L/∂b=z−y。对 x=2、y=3、w=0.5、b=0，z=1，L=2，梯度 dw=−4、db=−2。

同时更新且 η=0.1：w=0.9、b=0.2；新 z=2，新 L=0.5。所有梯度必须由同一个旧参数状态计算。如果先改 w 再用新 w 计算 db，这已经是不同算法。

乘法链条像逐段追问：损失随分数变多少？分数随参数变多少？把每段比例相乘。类比边界是：分支处还要把所有路径贡献相加，多变量不是只有一条线。

## 有限差分是一种检查，不是实际训练方案
中心差分 [L(w+ε)−L(w−ε)]/(2ε) 通常更准确，但 ε 太小会受浮点舍入影响，太大会偏离局部。检查用 float64 和 ε=1e−6；普通训练常用 float32。若模型有随机 Dropout，有限差分两次用了不同掩码，差值就混入随机变化，应先固定随机性或 eval。

逐个扰动数十万参数需要大量前向计算。自动求导记录前向运算关系，按链式法则反向累积导数；它不选择正确数据、损失、标签和学习率，也不保证模型学到你想要的东西。

```python
optimizer.zero_grad(set_to_none=True)
loss = criterion(model(x), y)
loss.backward()
optimizer.step()
```

zero_grad 清除上一次累积梯度；backward 计算并累加到参数的 .grad；step 读取梯度更新参数。遗漏清零会把多个批次梯度相加；有时梯度累积是有意设计，但需要正确缩放，不是偶然忘了清零。

## 实验 6：学习率大一点会怎样
假设“小步比大步更稳”。固定初值、数据和平方损失，只改变 η 为 0.01、0.1、1，手算五步并画损失。这个一维凸问题可给出解析结论，不应推广为深网络通用最佳学习率。观察交替震荡还是单调接近，先辨别原因，再试调度器。

# 第 7 章 亲手走完一次反向传播

## A：一颗隐藏神经元也能展示完整机制
输入 x=2；隐藏层 a=wx+b，初值 w=0.5、b=0，所以 a=1；ReLU(a)=max(0,a)，h=1。输出层两个分数 z₀=u₀h+c₀、z₁=u₁h+c₁，u=[1,−1]，c=[0,0]，真实类别 y=1。这是两分类教学例子，不是 MNIST 网络。

前向 z=[1,−1]；Softmax p≈[0.880797,0.119203]；L=−ln(p₁)≈2.126928。它预测 0，目标却是 1。下面每个数字都由 evidence/math.json 中 float64 自动求导复算。

## B：从输出依次往前
第一步：g=∂L/∂z=[0.880797,−0.880797]。

第二步：输出权重梯度 du_j=g_j h，因此 du=g；输出偏置 dc=g。

第三步：隐藏输出 h 同时影响两个分数，所以 dh=u₀g₀+u₁g₁=1.761594。分支贡献必须相加，不能只沿正确类的那条边传播。

第四步：a=1>0，所以 ReLU 导数为 1，da=dh=1.761594。接着 dw=da×x=3.523188，db=da=1.761594。

@figure backward | 图 5　两条输出路径的梯度在 h 汇合。黑色箭头是前向值，虚线箭头是反向导数；数值为手算教学示例。

η=0.1，同步更新得到 w≈0.147681、b≈−0.176159、u≈[0.911920,−0.911920]、c≈[−0.088080,0.088080]。新 a≈0.119203，仍为正；新 logits≈[0.020623,−0.020623]，新损失约 0.71398，精确值见数值表。这是一次明确更新带来的下降，不是“以后每次都下降”的证明。

## B：全连接层的通用形状
令 h∈R^d、W∈R^(K×d)、b∈R^K，z=Wh+b；g=∂L/∂z∈R^K。每个 W_ji 只直接影响 z_j，且导数是 h_i，所以：

@math \frac{\partial L}{\partial W}=g h^T,\quad \frac{\partial L}{\partial b}=g,\quad \frac{\partial L}{\partial h}=W^Tg

g hᵀ 是 (K,1)@(1,d)，结果 (K,d)；Wᵀg 是 (d,K)@(K,1)，结果 (d,1)。形状和参数一一对应。批次按行布局时 H∈R^(N×d)、G∈R^(N×K)，dW=GᵀH、db=∑_n G_n、dH=GW。如果 G 已包含平均损失的 1/N，就不能再除一次。

## ReLU 选择了哪些梯度路径
正输入导数 1，负输入导数 0，所以负区间向前一层的梯度被挡住。它不是把负参数删掉，而是本次输入经过这个单元时局部导数为零。某单元若对所有训练输入都处于负区间，可能长时间没有来自这条路径的更新。

最大池化把一个窗口的最大值传出去。反向时，输出梯度传给本次取得最大值的位置，其他位置贡献为零。若多个位置并列最大，数学上没有唯一普通导数；框架采用具体索引或子梯度规则。C 层讨论中应区分不同后端的选择，基础实验避免用并列值核验精确路径。

卷积同一权重用于多个空间位置，这些使用位置对损失的贡献在梯度中相加。一个 1D 卷积核长度 2，输入 [1,2,3]，把两个输出相加作为损失：第一个权重参与 1 和 2，梯度 3；第二个参与 2 和 3，梯度 5。共享的是参数，累计的是所有使用地点的导数，不是给每个位置新建权重。

# 第 8 章 为什么需要非线性与多层

## 多叠几个直线变换，仍是一条直线变换
若 h=W₁x+b₁，z=W₂h+b₂，代入得到 z=(W₂W₁)x+(W₂b₁+b₂)。中间没有非线性时，两层可合并为一层仿射变换；堆很多层不自动扩大这种模型的函数类型。

@math W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)

经典小例子是 XOR：二维输入 (0,0)、(1,1) 属于类 0；(0,1)、(1,0) 属于类 1。单个仿射分界不能把对角的两点与另外两点分开。加入非线性可以组合多个区域；这说明表达能力发生了变化，不保证训练算法一定找到好参数。

## ReLU 提供分段结构
ReLU 对负数输出 0，对正数保持原值。多组权重产生不同的分界，后续层再组合这些分段响应。模型可以学习输入与标签的统计模式，也可能记忆训练例子。不能用“神经网络从不记忆”来解释泛化。

现在 MLP 的增量只有一个隐藏层：784→64→ReLU→10。参数量 (784×64+64)+(64×10+10)=50,890。它比线性模型更多，但没有卷积的局部连接和共享结构。

```python
model = nn.Sequential(
    nn.Flatten(1), nn.Linear(784, 64),
    nn.ReLU(), nn.Linear(64, 10),
)
```

每层输入输出依次是 (N,784)、(N,64)、(N,64)、(N,10)。ReLU 没有参数；隐藏宽度 64 是教学选择，不是理论最佳值。

```powershell
& $py -m textbook.labs.train --model mlp --run my_mlp
& $py -m textbook.labs.evaluate --run my_mlp
```

evaluate 默认评估验证集，不碰测试集。成功检查点：best.pt 可加载，输出形状正确，验证矩阵总和 512。观察 linear 与 mlp 时固定数据划分、种子、优化器、学习率、batch、epoch 和预处理，记录耗时与参数量。相同 epoch 不代表相同计算成本，学习率相同也不代表各架构都已被公平调到最佳。

# 第 9 章 卷积：把同一把尺子滑过图片

## A：局部乘积求和
MLP 第一层给每个像素位置不同的连接权重。卷积先查看小窗口，用同一组权重在各位置重复计算。这种结构假定某种局部模式在不同位置都值得检测，因此为图像提供有用的归纳偏置。它不是提前指定“第 7 个通道必定寻找左弧线”。通道响应由训练结果决定，往往比一个命名笔画更复杂。

取输入 3×3、核 2×2：

```text
input             kernel
1  2  0           1  0
0  1  3           0 -1
2  0  1
```

无填充、步长 1，输出左上 1×1+2×0+0×0+1×(−1)=0；右上 2−3=−1；左下 0−0=0；右下 1−1=0。因此输出 [[0,−1],[0,0]]。这里的核是人为设置的教学例子，训练中的核一般随机初始化并被梯度更新。

@figure convolution | 图 6　同一个 2×2 核滑过四个窗口。局部位置变了，参数没有变。示意计算。

PyTorch Conv2d 实际计算互相关，没有先把核旋转 180°；深度学习语境中仍称卷积。只要从头学习权重，两种约定可对应，但手算与程序核的方向必须一致。参考 [R2]。

## B：多通道不是把结果随便叠起来
一个输出通道的核覆盖所有输入通道。若输入 C_in=3，核形状是 (3,k_h,k_w)，先分别逐位置乘积，再把输入通道与核位置的贡献求和，最后加一个输出偏置。输出 C_out 个通道就有 C_out 组这样的核。

@math Y_{o,r,s}=b_o+\sum_{c=0}^{C_{in}-1}\sum_{i,j}K_{o,c,i,j}X_{c,r+i,s+j}

这个式子为 stride=1、无 padding、dilation=1 的简式。一般索引要考虑步长、填充和膨胀；不要直接拿简式去解释任意配置。groups=1、有偏置时参数数为 C_out(C_in k_h k_w+1)，与图片宽高无关。

1→8、3×3：8×(9+1)=80 个参数。8→16、3×3：16×(72+1)=1,168。一个输出通道不是只对应一个输入通道，除非专门采用分组或深度卷积；本项目没有使用这些结构。

@figure channels | 图 7　一个输出通道汇总所有输入通道的局部乘积。多个输出通道各自拥有一组核。

## 输出尺寸：先算，再运行
单个空间方向输入长度 H，核长 k，填充 p，步长 s，膨胀 d，则输出长度为：

@math H_{out}=\left\lfloor\frac{H+2p-d(k-1)-1}{s}+1\right\rfloor

padding 在边缘补值，常用零；stride 决定窗口移动多少格；dilation 在核元素间留间隔，其有效长度为 d(k−1)+1。对 H=28,k=3,p=1,s=1,d=1，输出 28。对 p=0，输出 26。对 28,k=3,p=1,s=2，输出 14。二维高宽分别计算。

边缘窗口含补零而非真实图像，因此卷积的平移等变性通常在无限网格或适当边界条件下成立；有限图片、padding、stride、后续池化和展平分类层都会影响系统的平移响应。等变指输入平移时特征跟着平移，不等于最终类别完全不变。

## 池化和感受野
2×2 最大池化取窗口最大值。例如 [[1,4],[2,3]] 输出 4；它减少空间分辨率，没有可训练参数，也会丢失位置和非最大值信息。不能把“降低尺寸”说成没有损失信息。

定义 r 为某层一个位置覆盖的输入理论感受野大小，j 为相邻位置在原输入上的间隔。初始 r=1,j=1；有效核 k_eff=d(k−1)+1 时，r_new=r+(k_eff−1)j，j_new=js。padding 改变位置偏移和边界有效范围，不改变内部位置这个理论递推。

项目两组 3×3 卷积、2×2 池化：r 从 1→3→4→8→10，j 从 1→1→2→2→4。第二次池化一个位置理论上覆盖 10×10 输入；后续全连接组合所有位置，最终类别依赖更大范围。有效感受野的实际贡献通常并不均匀，理论覆盖不等于每个像素贡献相同。

@figure pooling | 图 8　最大池化与感受野递推。最大值保留、其他值丢失；反向梯度沿本次最大值位置传递。

# 第 11 章 让训练成为可复查的实验

## 训练、验证、测试，分别回答不同问题
训练集用于更新参数；验证集用于选超参数与选择权重；测试集用于在选择结束后估计表现。它们不能混在一起。反复观察测试结果再挑网络，相当于让测试信息参与选择，最终数字不再是一次独立检验。

项目基线从 MNIST 原训练 60,000 张中，用固定种子 42 的排列选前 5,000 张为验证，后 55,000 为训练，原测试 10,000 张保留。教学实验沿用这个划分方法；快速模式只取训练划分前 2,048、验证前 512，以及测试前 1,000。快速测试前缀不是类别均衡抽样，不能和项目的每类 100 张混淆矩阵直接当同一成绩。

@figure split | 图 9　数据流分工。训练更新参数；验证选择配置与 checkpoint；测试在选择冻结后使用。

划分依据索引，不只是三个数量。split.json 记录真实索引，config.json 记录哈希、种子、架构、设备、版本、标准化、优化器、耗时和参数量。记录固定种子有助于复现，不保证跨设备、跨版本逐位相同；并行计算和数值舍入都会造成差异。参考 [R3]。

## 每轮循环其实做了五件事
1. model.train() 选择训练行为；2. 从 loader 取批次；3. 前向计算 logits 与损失；4. 清梯度、反向、更新；5. 在独立验证数据上 eval 并记录。样本顺序用私有 torch.Generator 固定，DataLoader num_workers=0 便于 Windows 与 CPU 基础实验。

```python
model.train()
for x, y in train_batches:
    optimizer.zero_grad(set_to_none=True)
    logits = model(x)
    loss = F.cross_entropy(logits, y)
    loss.backward()
    optimizer.step()
```

此段要先 import torch.nn.functional as F。完整 train.py 使用全名 torch.nn.functional，所以不依赖这段别名。train_loss 是训练过程中不同参数状态下各批次损失的加权平均；val_loss 是轮末固定参数在验证集的评估。两者不是完全相同的测量条件。

## epoch、batch 和更新次数
epoch 是遍历训练数据一轮；batch 是一次输入的样本集合；每个批次通常对应一次优化器更新。2,048 张、batch=64，每轮 32 步；batch=128，每轮 16 步。相同 epoch 下，更大 batch 会减少更新次数；比较 batch 时应说明是否固定样本遍历次数、更新次数或时间预算。

项目 train_one_epoch 正确按样本数量汇总损失与正确数，但停止时有零批次边界，不能把 n=0 的占位 loss=0/acc=0 视为实际学习成绩。第 17 章会讨论这个基线细节。

基线联系：[S3] get_dataloaders 确认划分与增强；[S5] train_one_epoch/evaluate 确认加权统计与模式；教学模型始终使用独立 train.py。

## 保存、加载与断点续训是不同目标
教学包分别保存 best.pt 与 last.pt。best 使用验证准确率严格改善时的深复制权重，记录对应 epoch；last 是最后一轮参数。保存 config 包含模型名字、输入形状、标准化与图片处理版本。load_checkpoint 先构建同架构，再 load_state_dict，最后 eval。

# 第 12 章 优化器：如何使用梯度

## A：梯度下降和小批次梯度
普通梯度下降用整个训练集的平均梯度更新；随机或小批次梯度下降用部分样本估计。小批次噪声可能帮助也可能妨碍优化，不能把它说成必然有益。数据顺序、batch size 和学习率一起决定路径。

动量保存过去梯度的指数衰减累计，使方向不必完全跟随本次噪声。教学简式 v_t=βv_(t−1)+g_t，θ_t=θ_(t−1)−ηv_t。β=0 回到普通更新。也有人在第一式乘 (1−β)，那改变了统计尺度；公式约定需说清。PyTorch SGD 有初始化、dampening、Nesterov 等细节，本项目设 momentum=0.9，未启用 Nesterov。

## B：Adam 的两份记账
Adam 跟踪梯度的一阶指数平均 m 和平方梯度的二阶指数平均 v。平方不是方差本身；不减去均值平方时，v 是未中心化二阶统计。初始 m₀=v₀=0，早期平均被零初值压低，用偏差修正：

@math m_t=\beta_1m_{t-1}+(1-\beta_1)g_t
@math v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2
@math \hat m_t=\frac{m_t}{1-\beta_1^t},\quad\hat v_t=\frac{v_t}{1-\beta_2^t}
@math \theta_t=\theta_{t-1}-\eta\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}

以上为逐元素运算。β₁=0.9、β₂=0.999，首次 g=2：m₁=0.2、v₁=0.004；修正后 m̂₁=2、v̂₁=4；若忽略很小 ε，更新量约 η。负梯度会向相反方向更新。ε 防止极小分母，并影响数值，不能在代码中随意删除。

Adam 的自适应尺度不是自动寻找最佳学习率，仍需要外部 η。不同论文和实现可能把 ε 放在不同位置、采用不同融合路径。参考原始论文 [R5]，本书基本公式不是完整 API 算法规格。

## RMSprop 与 weight decay
RMSprop 主要跟踪平方梯度的衰减平均，用它缩放当前梯度；可选动量和中心化形式。本项目使用 PyTorch 默认非中心化 RMSprop。不要把“只跟踪第二份统计”说成与 Adam 其余行为完全相同。

平方参数惩罚 λ||θ||²/2 的梯度是 λθ。把它加入普通 SGD 梯度，更新包含 (1−ηλ)θ，因此与简单乘法衰减相联系。对于 Adam，若先把 λθ 加进 g，再进入 m、v，自适应缩放会作用于惩罚项；AdamW 将衰减与梯度统计分开，效果一般不同。

@math \theta_{new}=(1-\eta\lambda)\theta-\eta\,\mathrm{AdamGradientStep}

该式中的 AdamGradientStep 表示偏差修正后的梯度比例，不应再乘一次 η。基线 build_optimizer 使用 Adam(weight_decay=1e−4)，未设置解耦衰减；它不是 AdamW。教学实验 Adam(weight_decay=0) 是为了最初隔离机制。学习时别把这两个设置拼成一个不存在的模型。参考 [R6]、[R7]。

## 调度器不是准确率开关
基线默认 cosine，在 epochs>1 时，轮末 scheduler.step；最低学习率 1e−5。StepLR 的步长 max(1,epochs//3)，gamma=0.3。history 的 lr 是 step 后值，更接近下一轮学习率，不一定是这一轮实际使用的值。选择 none 或 epochs=1 没有调度器。

这些项目设置来自 [S4] build_optimizer/build_scheduler 和 [S6] fit，普通机制与框架默认值分别说明。

实验 12：只改变学习率或优化器中的一个。若比较 Adam 与 SGD，同时把 SGD lr 变大，就无法把全部差异归因于优化器；可以为每个优化器采用同样预算的验证搜索，但必须说明搜索过程。记录 loss、accuracy、时间与失败运行，而不是只保留最好的一张曲线。

# 第 13 章 BatchNorm、Dropout 与正则化

## 学会训练后再添加这些组件
正则化泛指限制拟合方式、改变目标或增加约束，使训练结果更适合某种泛化需求。它可能牺牲训练拟合，也可能改善验证表现；数据、模型和强度不同，结论不同。更深、更多参数、更大 batch、更多 epoch、更多正则化都不保证更好。

## B：BatchNorm2d 到底在哪些维度统计
输入 (N,C,H,W) 时，每个通道在 N、H、W 上汇总统计。对通道 c，M=NHW，先求 μ_c 和方差 σ²_c，然后 x̂=(x−μ_c)/sqrt(σ²_c+ε)，再输出 γ_c x̂+β_c。γ、β 每通道两个可学习参数；ε 避免分母问题。

@math \hat x_{n,c,h,w}=\frac{x_{n,c,h,w}-\mu_c}{\sqrt{\sigma_c^2+\epsilon}},\quad y=\gamma_c\hat x+\beta_c

PyTorch 训练前向使用有偏方差估计；更新 running_var 使用无偏估计。默认 momentum=0.1 表示 running_new=0.9×running_old+0.1×batch_stat，不是优化器动量同一个公式含义。推理默认用运行统计；训练用当前批统计并更新运行量。参考 [R8]。只有批大小 1 仍可能有 H×W 多个数，但极小有效样本统计可能不稳。

项目两层 BN 通道为 32、64，γβ 参数分别 64、128；running mean/var 是缓冲区，不计入可训练参数数。它们仍然必须保存到 state_dict。教科书中的简化公式应包含这些输入与模式条件。

## B：Dropout 保持的是期望，不是每次结果
项目 Dropout(p=0.25)：丢弃概率 p，保留概率 q=0.75。训练时独立掩码 m∈{0,1}，保留概率 q，输出 mh/q；评估时直接输出 h。E[mh/q]=E[m]h/q=qh/q=h。保持的是固定 h 条件下的期望，不是每次样本数值都相等。

@math \tilde h=\frac{m h}{q},\quad E[\tilde h\mid h]=h

若 h=6，q=0.75，保留时输出 8、丢弃时输出 0，平均期望为 6。它不是永久删除神经元，也不是训练后要把权重再乘一次 0.75；这是 inverted dropout 的约定。参考 [R9]。

## eval 和关闭梯度，各自解决一个问题
model.eval() 切换 BatchNorm、Dropout 等模块行为；torch.no_grad()/inference_mode() 控制自动求导与推理开销。eval 不会自动禁止梯度；no_grad 不会自动让 Dropout 停止随机丢弃。因此推理一般同时 eval 和关闭梯度。模型没有这些模块时 train/eval 可能数值一样，但不能据此认为两者可以互换。

实验 13：复制一个带 BN 与 Dropout 的小网络，同一输入分别 train、eval 前向，记录输出差异与 running_mean。固定权重和输入，只改变模式；不要在原项目全局模型上做 train 模式实验，避免改其运行统计。不能据此说明随机输出是错误，也不能比较不同单次掩码来宣布精度。

# 第 14 章 怎样知道学得好不好

## A：先看计数，再看百分数
Accuracy=正确样本数/总样本数。它回答当前抽样分布下总体正确比例。若某类特别多，总体成绩可能掩盖少数类失败。混淆矩阵 M_ij 表示真实 i、预测 j 的样本数；行是真实，列是预测。对角线正确，非对角线帮助找具体混淆。

@math \mathrm{Accuracy}=\frac{\sum_c M_{cc}}{\sum_{i,j}M_{ij}}

教学矩阵 [[8,2,0],[1,6,3],[0,1,9]] 有 30 个样本、23 个正确，Accuracy=76.6667%。类 2 的真实数量 10，预测为 2 的数量 12，TP=9，FP=3，FN=1。

@math P_c=\frac{TP_c}{TP_c+FP_c},\quad R_c=\frac{TP_c}{TP_c+FN_c}
@math F1_c=\frac{2P_cR_c}{P_c+R_c}

类 2 Precision=9/12=0.75，Recall=9/10=0.9，F1=0.818182。Precision 问“预测成它的有多少真是它”；Recall 问“真是它的有多少被找出”。不同任务对两类错误的成本不同。

@figure confusion | 图 10　三类教学混淆矩阵。用数字和行列标签表达含义，不依赖颜色。此图不是 MNIST 实测成绩。

## 零分母不能略过
某类从未被预测，Precision 分母为 0；某类根本不在样本里，Recall 分母为 0。这些指标数学上未定义。报告可以采用 zero_division=0，但必须标注政策并另列 support；也可显示“未定义”。F1 可直接写 2TP/(2TP+FP+FN)，分母为 0 时同样需要政策。

宏平均对各类指标等权；加权平均按 support 权重；总体 Accuracy 对每个样本等权。均衡抽样与自然分布下的总体 Accuracy 含义不同。项目每类 100 张探索矩阵共 1,000 张；训练后报告是完整测试 10,000 张；顶部指标则是历史验证记录，三者不可混称一个准确率。

## 少量样本有多不确定
10 个独立代表性样本对 8 个，80% 只是这次比例。即使采用二项抽样假设，Wilson 95% 区间也约为 49.0%–94.3%，很宽。网页随手挑的 10 个样本还可能不满足随机代表性，区间并不能修复抽样偏差。

校准需要检查输出概率和真实频率是否匹配，例如把最高概率分箱，对每箱同时记录平均概率与正确比例。分箱少样本同样不稳；MNIST 上的校准不自动适用于你拍摄的手写照片。参考校准论文 [R10]，基础包没有实现温度缩放，不把它写成当前功能。

## 曲线与错误样本，回答不同问题
训练 Loss 下降而验证 Loss 上升，提示过拟合或训练验证分布差异，但应先检查指标计算、模式和预处理。Accuracy 近乎不变而 Loss 下降，可能是排名未变但目标概率增加。Loss 上升而 Accuracy 升高，也可能是少数高置信错误抵消大量小改善。

错误图集中看几类原因：笔迹歧义、图像切边、粗细差异、处理反色、样本标签与可见图形不一致。特征图提供观察内部响应的窗口；不能把一张亮区域当成“该通道对最终 3 贡献的严格证明”，尤其各通道单独归一化后亮度尺度已不同。

实验 14：在验证错误图中先提出假设，再查看 processed input。固定模型，对同一原图只改变一种预处理选项。记录预测排序、概率和像素；不能凭挑选成功样本推出总体改进。开放题评估依据是实验控制、记录完整性与结论边界。

# 第 15 章 把自己的笔迹送进模型

## 用户图片为什么更容易出错
MNIST 是特定采集与处理条件下的单字符图像。鼠标粗笔、倾斜拍照、纸张阴影、边框、两个数字、背景杂物可能形成分布变化。预测自己的图片前，应先问“模型实际收到的 28×28 是什么”，而不是直接增加 epoch。

教学脚本要求一张白底深色的单数字图片；合成示例 synthetic_three.png 是程序画的折线，不是用户真实笔迹，也不代表完整用户图片评测。

## A：处理流水线分开做，才看得见问题
1. 解码为 RGBA，透明部分与白底合成；2. 转灰度；3. 反色，得到黑底亮字；4. 除以 255；5. 把 ≤0.12 的弱亮度置零，其余保留原值；6. 取非零外接框；7. 等比缩放，长边 20；8. 放入 28×28 黑底中心；9. 固定标准化；10. 增加批次、通道维。

教学白底模式没有自动背景判断；黑底图应先按约定转换，不要额外反色两次。空白在阈值后报错，不会送一个零输入后假装识别。应用的空白规则另见下一章。

## 外接框中心与亮度质心不同
外接框只看有笔画的最小矩形；几何居中把矩形放在画布中心。亮度质心为 x̄=∑xI(x,y)/∑I(x,y)、ȳ=∑yI(x,y)/∑I(x,y)，较亮或较粗区域权重更大。字形偏重一侧时，两种中心不同。

基线 _center_by_mass 名字和注释说质心，但实现按裁剪后宽高摆放，未计算亮度加权质心。基线 top=14−new_h//2；教学 top=(28−new_h)//2。当 new_h 为奇数时，两者可能相差 1 像素。因此“流程相近”不等于逐像素一致，教材不把独立包误称项目预处理的完全复制。

## 实验 15：分离预处理错误与模型错误
问题：笔迹识别失败是否由尺度引起？固定原图、模型权重、反色与标准化，只改变 auto_center 或目标框大小。保存每个处理预览，记录预测。如果某个选项改善这一幅，仍不能说明普遍更好；建立独立的用户笔迹验证集，保留标签，才可评估范围。

常见错误：PNG 透明背景变黑；浮点 0–1 当整数 0–255；把彩色 shape(H,W,3) 直接喂 NCHW；忘记 eval；使用旧架构加载新权重；先标准化再裁剪阈值导致背景判断异常。诊断顺序：文件→灰度→反色→裁剪→缩放→标准化→shape→模型→概率。

## 保存成功要独立核查
train.fit 每轮和最后保存当前模型，best_acc 只是历史最大验证 Accuracy；没有单独保存那次最佳权重。save_model 直接 torch.save 到目标文件，没有临时文件原子替换。保存异常可能只记录警告，任务继续结束；因此“任务结束”“running=false”“停止已收到”“服务已关闭”都不能充当保存成功证明。

实际核查：看日志是否保存成功；比较文件时间与大小；在可信环境重新加载，核对元数据与一次前向；重要实验保留旧备份和哈希。时间变了仍不是文件完整性证明，重载成功也不等于恢复了最佳模型或完整优化器现场。

## 停止发生的阶段决定结果
下面基线边界来自 fit、train_one_epoch、training_worker 与独立受控检查。不要把“停止并保存”按钮文案解释成所有分支相同。

|停止时点|基线行为|不能承诺|
|数据准备阶段|准备仍可能完成，轮前检查 STOP；无 history 时保留旧权重|立即停止下载或立即关闭|
|进入轮次之前|轮前 STOP 检查跳过训练，无 history 保留旧权重|已有新训练模型|
|轮前检查之后、首批检查之前|可出现 n=0；仍验证、追加 history 并保存新初始化模型|零批次必然保留旧权重|
|部分批次完成后|批边界退出，仍验证、记录部分轮次、保存当前参数|完整 epoch 或最佳权重|
|验证阶段|evaluate 不检查 STOP，等待验证结束|立即取消验证|
|报告阶段|报告路径不检查 STOP，可能完成全测试及绘图|报告立即中止或全部成功|
|保存异常|记录警告后可能继续 done、释放任务锁|done 必然意味着持久化成功|

零批次边界很少见，但源码并未把 n>0 作为追加 history 的条件。独立检查用临时模型和小数据模拟这个时间窗口，确认不会碰原权重。该结论不是修复建议已经被实现；原项目本次未改动。

## 识别能力从哪里来
输入像素携带字形的空间变化，参数化模型把变化映射成类别分数，损失让标注样本的目标类更有优势，梯度把输出误差连接到每个参与计算的参数，优化器重复更新。卷积让局部计算在不同位置共享，层间非线性让局部响应可以组合。这些机制共同构成识别能力，不是某一层突然获得数字意识。

泛化依赖训练分布、样本覆盖、归纳偏置与优化结果。模型可能同时学到有用规律和偶然关联。对 MNIST 有效，不保证对纸上拍照、特别粗的笔迹或陌生字形有效；十分类系统仍会对许多未知输入给出高概率。

## C：校验时常用的三条小推导
ReLU 分段复合产生分段仿射函数，但 Softmax 与交叉熵不再是仿射，分类边界与损失形状要分别讨论。最大池化同样是分段选择，非光滑点应避开精确有限差分检验。

卷积参数共享的梯度：若同一参数 θ 在多个运算节点 a_q 中使用，∂L/∂θ=∑_q(∂L/∂a_q)(∂a_q/∂θ)。这就是第 7 章 [3,5] 的一般形式，二维、多通道只增加求和索引，不改变链式法则。

Softmax 共同平移不变带来一个检查：单样本交叉熵输出梯度的和为 ∑p_j−∑1[j=y]=1−1=0。代码若偏离太多，应检查 batch 平均、标签或是否传错概率。
